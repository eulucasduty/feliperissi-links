# Página de links — Felipe Rissi

Site estático (HTML puro) publicado na Vercel em `feliperissi.com.br/pagina-de-links`.

- `pagina-de-links/index.html` — a página
- `pagina-de-links/img/` — banners (WebP)
- `vercel.json` — redireciona `/` para `/pagina-de-links`

Para trocar um link, edite o `href` do card correspondente em `pagina-de-links/index.html`.
Os cards do aplicativo e do devocional estão marcados com a classe `soon` até receberem link.
